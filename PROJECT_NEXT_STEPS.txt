2.1 FIX BACKEND WEBSITE DRIVER TEST (19 FAILURES)
--------------------------------------------------------------------------------
File: `backend/src/modules/template-engine/drivers/website.driver.test.js`
Cause:
  In commit `633ebb2`, `websiteDriver.execute()` added auto-publishing for newly
  seeded pages:
    `page = await updatePage(page.id, { status: 'PUBLISHED' }, userId);`
    `pageKeyToId[key] = page.id;`
  The test mock `updatePage` returns `undefined` by default in the test setup.
  When `page.id` is accessed, it throws:

  Update the mock in `website.driver.test.js`:

  ```javascript
  const updatePage = vi.fn().mockImplementation((id, patch) => {
    return Promise.resolve({
      id,
      slug: 'test-slug',
      title: 'Test Page',
      status: patch?.status || 'PUBLISHED',
      data: patch?.data || { content: [] },
    });
  });
  ```
Target: All 19 failed tests in `website.driver.test.js` pass.

4. STEP 3: SEO & DYNAMIC DETAIL PAGES HARDENING
================================================================================

Currently, dynamic sector pages at `/sectors/[slug]` generate client-side `<title>`
and meta tags via `useEffect`. Search engine bots (Google, Bing) and social
media link preview scrapers (Slack, Twitter, WhatsApp, LinkedIn) may not
execute client JavaScript to see these tags.

Action Items:
1. Implement Next.js App Router `generateMetadata`:
   File: `frontend/src/app/sectors/[slug]/page.tsx` (and site generator template)
   - Add asynchronous `generateMetadata({ params })`:
     ```typescript
     export async function generateMetadata({ params }): Promise<Metadata> {
       const sector = await fetchSectorBySlug(params.slug);
       if (!sector) return { title: 'Sector Not Found' };
       return {
         title: `${sector.name} | Subhadra Group`,
         description: sector.seo_description || sector.description,
         openGraph: {
           title: sector.seo_title || sector.name,
           description: sector.seo_description || sector.description,
           images: sector.og_image ? [{ url: sector.og_image }] : [],
         },
       };
     }
     ```
2. Mirror this pattern for `/catalog/[slug]` and `/work/[slug]` so every product
   and case study page generates crawler-ready meta tags.
