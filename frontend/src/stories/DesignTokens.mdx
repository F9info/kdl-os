# Design Tokens

KDL Starter Kit design tokens. All color values are driven by CSS custom properties that can be
overridden at runtime by the **Module 15 Theme Engine** via `--branding_*` and `--buttons_*`
variables (see `tailwind.config.ts` and [KDL-199](/KDL/issues/KDL-199)).

> **Theme Engine override behaviour:** `ThemeEngineProvider` injects a `<style id="th-tokens">` block into the document. Dark-mode values land in `:root`; light-mode values land in `[data-theme="light"]`. Every slot in `tailwind.config.ts` has a `var(--branding_*, hsl(var(...)))` fallback so the shadcn palette remains visible before the provider's first fetch resolves or when a token is unset.

## Spacing

Tailwind default spacing scale (4px base unit). Relevant custom container padding: `2rem` (32px).

| Token                   | Value    |
| ----------------------- | -------- |
| `container.padding`     | `2rem`   |
| `container.screens.2xl` | `1400px` |

---

## Border Radius

Controlled by `--radius` (default `0.5rem`). Override via Theme Engine Layout → Border Radius pane.

| Token        | Value                       |
| ------------ | --------------------------- |
| `rounded-lg` | `var(--radius)`             |
| `rounded-md` | `calc(var(--radius) - 2px)` |
| `rounded-sm` | `calc(var(--radius) - 4px)` |

---

## Typography

Inherits Next.js / browser defaults. Font family, size, and weight can be applied via Theme Engine
Typography pane tokens (`--branding_typography_*`) when the provider is active.

| Scale       | rem      | px (16px base) |
| ----------- | -------- | -------------- |
| `text-xs`   | 0.75rem  | 12px           |
| `text-sm`   | 0.875rem | 14px           |
| `text-base` | 1rem     | 16px           |
| `text-lg`   | 1.125rem | 18px           |
| `text-xl`   | 1.25rem  | 20px           |
| `text-2xl`  | 1.5rem   | 24px           |

## Light + Dark Mode

The app ships two shadcn palettes embedded in `globals.css`:

- **Light** (`:root`): white backgrounds, dark text.
- **Dark** (`.dark`): navy backgrounds (`hsl(222.2 84% 4.9%)`), light text.

The Theme Engine overrides both palettes at runtime by injecting `--branding_*` vars into
`:root` (dark) and `[data-theme="light"]` (light). Every Tailwind color slot in `tailwind.config.ts`
has a `var(--branding_*, hsl(var(...)))` fallback to keep the static palette visible before the
provider resolves.
