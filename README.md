# KDL Starter Kit

**Generic production-ready SaaS boilerplate by [Kalam Dream Labs Pvt Ltd](https://kalamdreamlabs.com)**

---

## Overview

KDL Starter Kit is a fully AI-agent-buildable SaaS foundation. Every service is containerised, every module is isolated, and every line of production code is generated by AI agents following a structured phase plan. Humans approve phases — not individual PRs.

The finished product is **KDL OS**: a modular, no-code project builder. One installation can run an **Admin** app, a **Website** (CMS, menus, visual Section Builder, themes, SEO, preview and publish), **Landing Pages**, forms and media, in any combination, and a Website can also be exported as a **static site**. Modules are installed and enabled from the admin (Settings > Products and Modules); no source edits are needed to build a project.

| Layer | Technology |
|-------|-----------|
| Backend | Node.js 20 + Express 5 + Prisma 6 |
| Database | PostgreSQL 15 (host port 5433) |

| Storage | MinIO (port 9000) |
| Search | MeiliSearch (port 7700) |
| Reverse Proxy | Nginx |
| Package Manager | pnpm (monorepo) |

## Quick Start

New to this? Follow the step-by-step guide: [docs/INSTALLATION_GUIDE_SIMPLE.md](docs/INSTALLATION_GUIDE_SIMPLE.md) (full version: [docs/INSTALLATION_GUIDE.md](docs/INSTALLATION_GUIDE.md)). In short:

```bash
# 1. Configure environment (the guide shows how to generate the secrets)
cp .env.example .env
# Set at least JWT_SECRET and the database/redis passwords.
# Optional: OPENROUTER_API_KEY / ANTHROPIC_API_KEY (AI features only)

# 2. Start all services. The backend applies database migrations on start.
docker compose up -d --build
docker compose ps            # wait until `backend` is healthy

# 3. Create the admin user (first run only)
docker compose exec backend node prisma/seed.js
```

Then open http://localhost/login, sign in as `admin@kdl.com`, and the Setup Wizard walks you through company identity and which products (Website, Landing Pages) to turn on.

Forgot the admin password: `docker compose exec backend node scripts/reset-admin-password.js --email admin@kdl.com --password 'NewPassword123'`

| Service | Username | Password |
|---------|----------|----------|
| Admin panel | admin@kdl.com (or `SEED_ADMIN_EMAIL`) | `SEED_ADMIN_PASSWORD` if set, else random — printed once by the seed. Docker stack pins `kdl-dev-seed-password` |

**Change all passwords before deploying to production.**

## Production Run

```bash
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d
```

Production overrides: `restart: always`, `NODE_ENV: production`, no host ports exposed except Nginx :80.
