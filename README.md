# KDL Starter Kit

**Generic production-ready SaaS boilerplate by [Kalam Dream Labs Pvt Ltd](https://kalamdreamlabs.com)**

---

## Overview

KDL Starter Kit is a fully AI-agent-buildable SaaS foundation. Every service is containerised, every module is isolated, and every line of production code is generated by AI agents following a structured phase plan. Humans approve phases — not individual PRs.

The finished product is the **KDL OS Kit**: a SaaS skeleton with Auth, Data Model Builder, Dynamic API, Admin Panel, Form Builder, and Project Management built in.

---

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Backend | Node.js 20 + Express 5 + Prisma 6 |
| Database | PostgreSQL 15 (host port 5433) |
| Cache / Queue | Redis 7 + BullMQ (host port 6380) |
| Frontend | Next.js 15 App Router + TypeScript 5 |
| UI | TailwindCSS 3 + shadcn/ui + Zustand 5 + TanStack Query 5 |
| AI Services | LangChain.js + ChromaDB + OpenRouter API |
| Storage | MinIO (port 9000) |
| Search | MeiliSearch (port 7700) |
| Reverse Proxy | Nginx |
| Package Manager | pnpm (monorepo) |

## Quick Start

```bash
# 1. Configure environment
cp .env.example .env
# Fill in: JWT_SECRET, OPENROUTER_API_KEY, SMTP_USER, SMTP_PASS
# Optional: ANTHROPIC_API_KEY (needed for CRITICAL/HIGH AI tasks)

# 2. Start all services
docker compose up --build

# 3. Run database migrations + seed (first run only)
cd backend && npx prisma migrate dev && node prisma/seed.js
```

## Production Run

```bash
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d
```

Production overrides: `restart: always`, `NODE_ENV: production`, no host ports exposed except Nginx :80.
